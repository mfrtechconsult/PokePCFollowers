# PokéPC Followers v0.6.1

Corrective release for the Generation II follower artwork introduced in 0.6.0.

- Replaces all 100 downscaled HGSS/PokeMMO sheets for Pokémon #152–#251 with native 16×96 GSC-style follower sheets from the PokéPC / Followers EX / Pokémon Crystal Clear lineage.
- Restores clean silhouettes and readable pixel art for affected Pokémon such as Suicune, Lugia, and Ho-Oh.
- Keeps Crystal 251 integration and the existing Dramatic Shape, Dramatic Sky Ride, Kanto Dive, and standalone Dramatic Deep Dive compatibility behavior unchanged.
- Adds regression checks for the reported Suicune, Lugia, and Ho-Oh assets.

Crystal 251 remains an optional dependency and is required only when using Pokémon #152–#251.
